# Logo

Drop your logo here as `logo.png` (or `logo.svg` — then update the `src`
in index.html's `#brandLogo`). The header sits on a navy background, so a
**white / light** version of the logo works best.

Recommended: height ~34px display size, so a 2x asset around 68px tall (or
an SVG). Once `assets/logo.png` exists and you push, it appears top-left
automatically and the text wordmark hides itself.
